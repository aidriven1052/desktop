🔧 키워드 추천 시스템 - 실행 안될 때 해결 방법
=====================================================

문제 1: "streamlit은(는) 내부 또는 외부 명령이 아닙니다" 에러
-----------------------------------------------------

✅ 해결책 1: 간편실행.bat 사용
   → 바탕화면의 "간편실행.bat" 파일을 더블클릭하세요
   → 자동으로 설치하고 실행됩니다

✅ 해결책 2: 수동으로 실행
   1. 명령 프롬프트(cmd) 열기
   2. 다음 명령어 입력:

      cd C:\WINDOWS\system32\Wcm
      python -m pip install streamlit pandas requests
      python -m streamlit run keyword_finder_improved.py

✅ 해결책 3: Python 경로 확인
   1. 명령 프롬프트에서:
      python --version

   2. 버전이 나오면 OK, 에러나면 Python 설치 필요
      → https://www.python.org/downloads/

=====================================================

문제 2: "pip은(는) 내부 또는 외부 명령이 아닙니다" 에러
-----------------------------------------------------

✅ 해결책:
   python -m ensurepip --upgrade
   python -m pip install streamlit pandas requests

=====================================================

문제 3: 설치는 되는데 실행이 안됨
-----------------------------------------------------

✅ 해결책 1: 파일 위치 확인
   keyword_finder_improved.py 파일이 있는 폴더로 이동:

   cd 파일이_있는_폴더
   python -m streamlit run keyword_finder_improved.py

✅ 해결책 2: 절대 경로로 실행
   python -m streamlit run C:\전체\경로\keyword_finder_improved.py

=====================================================

🆘 그래도 안되면?
-----------------------------------------------------

아래 정보를 복사해서 알려주세요:

1. Windows 버전 확인:
   winver

2. Python 버전 확인:
   python --version

3. pip 위치 확인:
   python -m pip --version

4. 에러 메시지 전체를 복사해서 보내주세요!
